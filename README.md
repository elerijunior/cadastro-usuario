Cadastro de Usuários

Aplicação web para cadastro e gerenciamento de usuários, desenvolvida com React e Vite.

O projeto foi desenvolvido com foco na prática de desenvolvimento front-end, trabalhando conceitos de componentes, gerenciamento de estado, formulários e operações de CRUD.

React

Cadastro de usuários
Listagem de usuários
Edição de usuários
Exclusão de usuários
Gerenciamento dos dados através de uma interface web
🖥️ Projeto

A aplicação possui uma interface para gerenciamento de usuários, permitindo realizar as principais operações de um CRUD de forma simples e intuitiva.

CRUD significa Create, Read, Update e Delete — as operações básicas para criação, consulta, atualização e remoção de dados.

⚙️ Como executar
Pré-requisitos

Antes de iniciar, você precisa ter instalado:

Node.js
npm
Instalação

Clone o repositório:

git clone https://github.com/elerijunior/cadastro-usuario.git

Acesse a pasta do projeto:

cd cadastro-usuario

Instale as dependências:

npm install

Execute o projeto:

npm run dev

Após iniciar o servidor de desenvolvimento, acesse o endereço informado pelo Vite no terminal.
